青云梯

青云梯把机场订阅交到你常用的客户端里，用来完成梯子式的网络加速。本页按阅读顺序写清适用场景、操作步骤，以及如何按设备选择客户端。

关于青云梯

青云梯是一项机场订阅服务。你完成订阅后，把链接导入电脑或手机上的代理客户端，即可在需要时开启网络加速，访问平时不易稳定打开的站点与工具。

它解决的是“配置从哪来、在哪用”的问题：套餐提供订阅，客户端负责连接。二者分开选择，也因此客户端是否匹配系统、导入是否正确，往往比纠结名词更影响第一次能否连上。

以下内容按编辑稿件的方式铺开：左侧把背景说清，右侧列出上手顺序；随后是场景、逐步说明、客户端专区与套餐入口，最后用问答覆盖常见卡点。价格与下载通道以页面中注入的模块为准，正文不改写套餐数值，也不另给下载地址。

先选客户端再连接

  1. 确认主力设备的系统，再进入客户端区域下载。
  2. 同一时间只开一个代理客户端，避免系统代理冲突。
  3. 导入订阅后必须执行更新，再选择节点或策略。
  4. 先在一台设备跑通，再复制同一订阅到其他设备。

客户端决定你怎么点、怎么排规则；订阅只提供可更新的配置来源。本页把客户端选择单独成章，就是为了减少“套餐买了却打不开”的情况。

使用场景

青云梯适合把网络加速当作工具、而不是把全部流量时刻挂着的人。下面几类情境最常见，可对照自己的设备与时段来判断。

学习与资料

查阅论文、文档站点、开源仓库或在线课程时，用订阅在客户端里按需开启，读完再关掉，减少对日常上网的干扰。

远程协作

和海外同事共用文档、会议或开发面板时，稳定的出网路径比追求花哨界面更重要。选你熟悉的桌面客户端即可。

出行与多地生活

在不同网络环境下仍要打开常用账号与服务，把订阅放进手机客户端，比临时寻找公开节点更可预期。

内容与工具访问

浏览跨区域媒体、软件源或控制台时，用客户端的分流或手动开关，只加速需要的应用，其余流量走本地网络。

操作说明

流程只有五步。名称在不同客户端里可能叫“订阅”“URL”“配置”或“Profiles”，含义相同：把青云梯发给你的链接读进去，再更新一次。

1. 浏览并确认套餐

到本页套餐区域查看当前方案，按使用周期选择后完成订阅。正文不重复价格数字，以免与实时展示不一致。

2. 保存订阅信息

把订阅链接存放在可复制的地方。链接是客户端的输入，不是安装包；丢失后需回到账户侧重新查看，而不是重装软件。

3. 按系统下载客户端

Windows、macOS、Android、iOS 的安装方式与权限提示不同。先锁定你每天用得最多的那台设备，只装一个主力客户端。

4. 导入链接并更新

打开客户端的订阅或配置入口，粘贴链接，执行更新或拉取。等到列表刷新完成，再去选节点、策略组或规则模式。

5. 连接后做一次小检查

开启连接，用浏览器打开一个你本来打不开或很慢的页面。若失败：先更新订阅，再换一条线路，最后才考虑换客户端。不要同时开两个代理应用。

客户端选择

青云梯的订阅需要落到具体客户端上才会工作。选择标准很务实：系统能安装、你能看懂按钮、社区或自带说明足够让你完成“导入—更新—连接”。不必在第一次就追求规则最全的版本。

桌面系统适合带策略和日志的客户端，出了问题能看见当前走的是哪条路径。手机端更依赖系统允许的 VPN/代理能力，安装来源也更需要核对。同一条订阅通常可以在多台设备重复导入，但界面、分流方式和开机行为并不通用，所以以设备为单位选择，而不是强行统一成一个名字。

建议顺序：主力电脑或主力手机 → 下载对应客户端 → 导入青云梯订阅并更新 → 确认可以访问 → 再考虑第二台设备。下方模块由站点注入真实客户端入口，请按系统点选，不要使用来路不明的安装包。

常见问题

青云梯是什么？和客户端是什么关系？

青云梯提供机场订阅，也就是一组可更新的配置来源。客户端是安装在你设备上的程序，负责读取订阅、建立连接。没有客户端，订阅无法单独“上网”；没有订阅，客户端没有可更新的配置。本页同时说明这两部分，并把客户端选择写得更靠前。

第一次用，应该先下客户端还是先看套餐？

先确认套餐能覆盖你的使用周期，再按设备下载客户端。原因很简单：订阅链接是导入用的，安装包是系统相关的。顺序反了容易装了一堆软件却还没有可粘贴的链接，或买完却发现主力手机装不上所选类型。

如何判断自己选对了客户端？

三件事同时成立即可：能在当前系统安装；能找到导入订阅或 URL 的入口；更新之后能选出线路并成功打开一个目标站点。界面是否花哨、功能是否最多，都排在这三项之后。若导入后列表为空，优先检查链接是否完整、是否已点更新，而不是立刻换下一个软件。

电脑和手机能共用同一条青云梯订阅吗？

可以。订阅与设备数量不是一一对应的安装包关系，同一链接往往可在多端导入。注意两点：各端分别选择匹配的客户端；不要在同一台设备上同时开启多个代理程序，以免端口或系统代理互相覆盖。

连接失败时应该按什么顺序排查？

先看本地网络是否本身可用，再在客户端内更新订阅，然后更换线路或策略。仍不行就重启客户端，检查系统是否还残留其他代理。最后才考虑更换客户端版本。把“节点好不好”放在确认导入成功之后，能少走很多弯路。

更新订阅以后要重新下载客户端吗？

一般不必。订阅更新是客户端内部的操作，用来刷新配置。只有客户端无法解析链接、无法安装，或系统版本已经不支持该应用时，才需要更换或升级客户端本身。日常维护以“打开客户端 → 更新订阅”为主。
